# Kovida Munnangi — AI/ML Portfolio

A multi-page, recruiter-friendly portfolio built with React + Vite.

## Pages

- Home
- About
- Projects
- Individual project case studies
- Contact

## Included projects

1. Person Detection During Floods Through Drone Technology
2. Multilingual Twitter Hate Speech Detection
3. Early Detection of Parkinson's Disease
4. Real-Time Multi-Client Chat Server
5. Employee Burnout Prediction
6. AI-Enabled Diagnostic Frameworks in Healthcare

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Main portfolio data is in:

`src/data/projects.js`

Update project descriptions, metrics, links, and technologies there.

Personal details are mainly in:

`src/pages/About.jsx`
`src/pages/Contact.jsx`

## Deploy

This project can be deployed to Vercel, Netlify, GitHub Pages, or another static hosting provider that supports Vite builds.

## Important

The portfolio deliberately avoids claiming Generative AI expertise. It presents Kovida primarily as an AI/ML Developer / Machine Learning Engineer and leaves room to add GenAI projects as those skills are developed.
